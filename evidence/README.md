# Evidence (small, permanent, in git)

Generated by `./ckt export-evidence`. Large data lives in Cloudflare R2 (bucket `ckey-hardening-test`), content-addressed: every object is `cas/sha256/<aa>/<sha256>` and its hash is listed in `r2_index.jsonl` and in the shard records under `manifests/`.

* `state/` lock (gate approval, config/spec/worker hashes) and transition log
* `manifests/` one line per sealed 1,000-case shard: plan/results/traces SHA-256
* `reports/` campaign reports, freeze records and signatures, gate evaluation
* `counterexamples/<case_id>.json` exact case lines: `./ckt repro` regenerates the frames bit-for-bit
* `svg/<sha256>.svg.gz` the production SVG of those cases (gzip -9); `svg_sha256` in results matches the uncompressed file
* `ml/` model weights and model card
